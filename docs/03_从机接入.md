# 从机接入

先完成[主机配置](02_主机共享与本地管理.md)，再在从机运行：

```bash
./network_setup.sh client
```

选择连接主机的实际有线/Wi-Fi 接口，再选择联网策略：

| 策略 | 地址与默认网关 |
|---|---|
| DHCP 自动获取 | 地址、网关和 DNS 由上游 DHCP 提供 |
| 固定 IP，持久默认网关 | 保存固定地址、网关和 DNS |
| 固定 IP，按需临时网关 | 保存固定地址和 DNS；网关仅作为按需使用的建议 |
| 固定 IP，仅本地管理 | 保存固定地址，不添加网关和 DNS |

## 固定地址示例

有线连接先填写自定义名称，例如 `robot客户端`。沿用主机的地址输入：

```text
网段：192.168.1.0/24
主机地址末段：20
从机地址末段：30
```

从机地址为 `192.168.1.30/24`。持久网关模式保存 `192.168.1.20`；按需模式只记录该地址供临时路由使用。DNS 默认建议主机地址，前提是主机共享已经提供 DNS；可改为实际可达的 DNS。

静态地址必须在 DHCP 池之外，或经过统一地址管理。主从地址必须不同，不能使用网络地址或广播地址。无线接入需填写已有热点 SSID、安全方式和密码。

## 验证与保存

先测试主机管理地址，确认 SSH 等本地通信正常；需要公网路径时分别测试路由和代理。输入 `KEEP` 才保存，试运行名称带 `[试运行]`，有线确认后使用自己填写的名称。

按需网关模式的后续联网操作见[临时联网路由](05_临时联网路由.md)。应用代理独立工作，见[应用代理](06_应用代理.md)。同网段代理可在没有公网默认路由时工作，因此撤销默认路由不会一并关闭代理。
