# 连接管理与备份恢复

连接配置与物理网卡不同；管理和删除配置不会删除网卡。操作以 UUID 为准，名称仅用于显示。

## 管理已有连接

主菜单选 **5**：

| 操作 | 行为 |
|---|---|
| 查看详情 | 显示普通有线/Wi-Fi 配置详情 |
| 激活已有连接 | 选择对应物理网卡，检查点试运行并等待 `KEEP` |
| 安全断开指定网卡 | 只断开选中的接口，使用检查点保护 |
| 关闭/开启自动连接 | 备份后修改选定连接的自动启动策略，不立即改当前 IP |
| 备份配置 | 创建可用于恢复的私有单连接 JSON |
| 批量删除非活动配置 | 检查活动状态、来源和凭据，输入 `DELETE` 后备份并删除 |

当前活动配置不能直接删除。删除前和每次删除时均检查所有接口上的活动 UUID。`/run/` 生成配置、企业认证或无法完整备份凭据的连接不自动删除；需检查实际持久源。配置切换成功后再手动退役旧连接，程序不会静默删除原用户连接。

## 两种备份

系统配置归档：

```bash
./network_setup.sh backup
```

归档包含存在的 `/etc/NetworkManager`、`/etc/netplan` 和 `/run/NetworkManager/system-connections`，保存至 `/var/lib/netpilot/backups/system/`。它是源配置归档，不包含完整内核运行状态，也不提供自动全目录恢复。

单连接 JSON：主菜单 **5 → 备份配置**，保存至 `/var/lib/netpilot/backups/profiles/`。连接删除、部分修改等操作也会创建该类备份。

两种备份都可能含密码，仅 root 可读，权限不等于加密。不要把真实备份提交到仓库。

## 从单连接备份恢复

```bash
./network_setup.sh restore
```

或主菜单 **9 → 从私有连接备份恢复**。选择 JSON 和目标物理网卡，程序创建新 UUID，试运行后输入 `KEEP` 保存，不覆盖现有同 UUID 配置。

菜单无选项时，先确认已有合格的单连接 JSON；系统归档不会出现在此菜单。记录了凭据缺失的备份不能自动恢复，外部证书/私钥引用要求原文件仍存在。

## JSON 计划导出与导入

配置确认成功后可导出 JSON 计划和 Markdown 配置卡至 `~/netpilot-exports/`，不包含 Wi-Fi/代理密码，仍含地址和 SSID。先预览示例：

```bash
./network_setup.sh --dry-run --plan examples/client_static.json
./network_setup.sh --dry-run --plan examples/host_shared.json
```

主菜单 **10** 导入时会重新选择当前设备的接口，密码在应用时输入；静态预览不能证明现场接口存在或没有地址冲突。`--plan` 实际应用不会交互重新映射接口，跨设备导入宜使用菜单入口。
