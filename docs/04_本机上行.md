# 本机上行

上行是当前设备访问其他网络的连接。主机共享前，应先建立可用上行。

```bash
./network_setup.sh uplink
```

## 有线上行

1. 选择实际有线网卡并输入连接名称。
2. 选择 DHCP 或固定 IPv4。
3. 固定地址模式填写完整地址/前缀、同网段网关和至少一个可用 DNS。
4. 选择确认成功后是否开机自动连接。
5. 验证地址、路由和 HTTPS，输入 `KEEP` 保存。

例如固定地址可填写 `192.168.10.50/24`、网关 `192.168.10.1`，DNS 使用该网络实际提供的地址；不要直接套用示例到其他网络。

## Wi-Fi 上行

选择无线网卡，查看已有扫描结果，填写 SSID、WPA2/WPA3 Personal 和是否隐藏。密码仅在应用时输入。企业认证网络不由本向导新建，可通过主菜单 **5 → 激活已有连接** 使用系统已经配置的连接。

Wi-Fi 射频关闭时，可在主菜单 **12** 单独确认开启。此操作影响全机 Wi-Fi，可能触发已有配置自动连接，不属于设备连接检查点；硬件 rfkill 需自行解除。

## 检查实际出口

```bash
./network_setup.sh --status
ip -4 route get 1.1.1.1
```

多个默认路由、VPN 和策略路由可能改变实际出口。新上行连接不会自动关闭其他连接的自动启动；退役旧连接见[连接管理](08_连接管理与备份恢复.md)。
