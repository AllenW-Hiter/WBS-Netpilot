# 开始使用

NetPilot 在每台设备上分别运行。**主机**向下游提供共享或管理地址；**从机**通过该链路接入；**上行**是本机访问其他网络的接口；**下行**是主机面向从机的接口。

## 环境准备

使用 Ubuntu/Debian 系 Linux、系统 `/usr/bin/python3`、NetworkManager 和 systemd。网卡须由 NetworkManager 管理。Conda/虚拟环境不能替代系统 `python3-dbus`。安装缺失软件包需要已有网络，完全离线时程序会停止；安装 NetworkManager 可能启动服务。

保留整个项目目录，在本机终端执行：

```bash
chmod +x network_setup.sh
./network_setup.sh --check
./network_setup.sh --demo
./network_setup.sh
```

`--check` 输出工具路径、Python 和服务状态，不安装或改网；缺失项目需按所用功能处理。`--demo` 展示通用主从计划，不检测或应用到当前设备。进入写操作时启动器调用 sudo。

## 主菜单

| 编号 | 功能 |
|---|---|
| 1 | 查看网卡与状态 |
| 2 | 配置主机／共享网关 |
| 3 | 配置从机／客户端 |
| 4 | 配置本机上行 |
| 5 | 管理已有连接 |
| 6 | 临时联网路由 |
| 7 | 应用代理 |
| 8 | 停止有线共享但保留管理地址 |
| 9 | 备份／恢复 |
| 10 | 导入 JSON 计划 |
| 11 | 诊断与导出报告 |
| 12 | 开启 Wi-Fi 无线功能（全局） |
| 0 | 返回／退出 |

菜单只提供可选物理有线/Wi-Fi 网卡；Docker 网桥、P2P、未托管接口等仍可在状态页面查看。

主菜单 **7 → 6** 可[配置当前用户 GitHub SSH 密钥](10_GitHub_SSH密钥.md)。也可直接运行 `./network_setup.sh github-ssh`；此入口无需 sudo 或 NetworkManager，只使用 Python 和 OpenSSH 客户端。

## 试运行与确认

新连接先以 `autoconnect=false` 在内存中激活。程序预览计划、备份并建立原生检查点；默认 180 秒内验证地址、SSH 和所需联网路径后输入完整大写 `KEEP`。输入其他内容撤销；未确认由 NetworkManager 超时保护。检查点建立失败就停止。

SSH 断线后，在重连终端使用实际事务编号：

```bash
./network_setup.sh confirm a1b2c3d4e5f6
./network_setup.sh rollback a1b2c3d4e5f6
```

需要更多验证时间时：

```bash
./network_setup.sh --timeout 300 host
```

全局参数必须放在子命令前。`--timeout` 支持 120～900 秒。检查点无法恢复拔线、断电等硬件故障，改 IP 前应保留本机或独立恢复通道。
