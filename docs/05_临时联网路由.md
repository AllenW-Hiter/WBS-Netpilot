# 临时联网路由

适用于已配置固定地址、平时只需本地管理的从机。主机须已经开启共享，网关须与从机当前地址在同一网段。

## 开启

```bash
./network_setup.sh route-on
```

选择从机接口，填写主机下行地址，例如 `192.168.1.20`，再填写 metric。metric 越小通常优先级越高；已有同 metric 默认路由时，程序要求重新选择，避免歧义。

程序只增加带 `proto 242` 标记的一条精确 IPv4 默认路由，不替换其他路由。修改前安排独立 systemd 定时恢复任务；无可用 systemd 时停止。验证公网路径后输入 `KEEP` 确认。

SSH 重连后也可通过实际事务编号执行：

```bash
./network_setup.sh confirm a1b2c3d4e5f6
./network_setup.sh rollback a1b2c3d4e5f6
```

## 关闭

```bash
./network_setup.sh route-off
```

选择本工具登记且仍存在的路由，确认并输入 `KEEP`。没有归属记录的路由不会删除。可在主菜单 **6 → 查看本工具路由记录** 查看当前记录。

临时路由不写入持久配置，重启或 NetworkManager 重建连接后可能消失。关闭只影响选中的这条路由，其他接口、默认路由和应用代理仍可能提供网络访问。

## DNS 与验证

临时路由操作不修改 DNS。按需网关的从机配置应已有可用 DNS；仅本地管理模式若没有 DNS，需另行配置。先检查 `ip -4 route get 1.1.1.1`，再用[诊断教程](07_诊断与故障处理.md)中的直连 HTTPS 测试验证，避免继承代理造成误判。
