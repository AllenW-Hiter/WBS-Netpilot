# 主机共享与本地管理

主机先建立可用上行，再选择面向从机的下行接口。仅直连管理无需上行。

```bash
./network_setup.sh host
```

## 选择模式

| 模式 | 所需接口 |
|---|---|
| 有线上行 → Wi-Fi 热点 | 一个已连接有线接口、一个支持 AP 的无线接口 |
| Wi-Fi 上行 → 有线共享（控制robot常用） | 一个已连接无线接口、一个有线下行接口 |
| Wi-Fi A 上行 → 独立 Wi-Fi B 热点 | 两个不同物理 `phy` 的无线接口 |
| 有线 A 上行 → 有线 B 共享 | 两个不同有线接口 |
| 仅有线直连管理（不启用 DHCP/NAT） | 一个有线接口 |

选择上行只用于检查和提示，NAT 出口跟随主机系统路由。实际出口与所选接口不同，向导要求输入 `FOLLOW` 接受现状；需要调整出口时先处理系统路由再重试。

## 填写名称与地址

有线新连接需输入名称，支持 1～100 个可打印字符，包括中文和空格；与其他用户配置重名时重新填写，保留原配置。

以下示例用于专用直连链路，两端分别填写相同的网段与地址：

```text
连接名称：robot主机共享
网段：192.168.1.0/24
主机地址末段：20
从机地址末段：30
```

主机得到 `192.168.1.20/24`，从机地址建议为 `192.168.1.30/24`。网段可简写 `192.168.1`，末段可写 `20` 或 `.20`，也可写完整 IPv4。支持 `/8～/30`，网段不能与其他接口、Docker 网桥或 VPN 路由冲突。

主机操作只配置主机。从机需按[从机教程](03_从机接入.md)单独配置。选择 DHCP 时，从机实际地址由 DHCP 分配，建议地址不是保留租约。

## DHCP 与热点

NetworkManager 支持 `shared-dhcp-range` 时，可设置不包含主从固定地址的 DHCP 池，例如 `.100～.199`。不支持或使用自动池时，向导要求选择“下游全部 DHCP”或“专用单台静态从机且不混接 DHCP”。自动池不能保证为静态从机预留地址。

热点需填写 SSID、安全方式、频段和信道；默认 SSID 为 `NetPilot-AP`。提供 WPA2/RSN+CCMP 和 WPA3 Personal，失败不会降级到开放热点。热点密码在实际应用时单独输入，不进入计划文件。

## 验证与停止共享

检查主从机能够互相访问，再在从机验证 DNS 和 HTTPS；主机显示连接已激活不能证明从机可以上网。验证后输入 `KEEP` 保存，开机自动连接按向导中的选择设置。

停止本工具创建的有线共享时，主菜单选 **8**，选择连接并试运行确认。程序保留同一管理地址，关闭该连接的 NetworkManager DHCP/NAT；其他软件的转发和代理不受此功能控制。
