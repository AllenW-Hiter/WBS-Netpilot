# 主机 Wi-Fi 上行与有线共享

## 任务

让实验室主机通过无线网卡连接 Wi-Fi，并通过另一张有线网卡向机器人共享网络。有线连接名称使用 `机器人控制网络`，主机有线地址为 `192.168.1.20/24`，机器人使用 `192.168.1.30/24`。机器人地址需要在[第二篇教程](02_客户端静态IP.md)中单独配置。

主机需要一张可用无线网卡和一张有线网卡，二者由 NetworkManager 管理。用网线连接主机有线口与机器人。实验室 Wi-Fi 网段应与 `192.168.1.0/24` 不重叠；如果 Wi-Fi、其他接口或路由已占用这个网段，先协调一个不冲突的控制网段，并同步修改两端参数。

## 通过 NetPilot 执行

### 1. 查看网卡，建立 Wi-Fi 上行

在主机的项目目录运行：

```bash
./network_setup.sh --check
./network_setup.sh --status
```

确认实际无线、有线网卡名称。无线已经连接且可以上网时，直接进入下一步。否则运行：

```bash
./network_setup.sh uplink
```

这相当于主菜单 **4. 配置本机上行**。选择无线网卡，上行地址方式选 **1. DHCP**，填写实验室 Wi-Fi 的 SSID，选择实际的 WPA2/WPA3 安全方式，并按提示填写是否隐藏、是否开机自动连接。确认试运行后输入 Wi-Fi 密码。

在另一终端检查上行：

```bash
ip -4 route get 1.1.1.1
curl -q --proxy '' --noproxy '*' -I --max-time 10 https://example.com
```

确认路由经过所选无线接口且 HTTPS 请求可以完成，再回到向导输入 `KEEP` 保存 Wi-Fi 连接。尚未完成的上行事务应先确认或撤销，再创建下行共享。

### 2. 配置有线共享

为配置机器人留出时间，将这次共享试运行时限设为 900 秒：

```bash
./network_setup.sh --timeout 900 host
```

这相当于主菜单 **2. 配置主机／共享网关**。依次填写：

| 软件提示 | 选择或输入 |
|---|---|
| 主机模式 | **2. Wi-Fi 上行 → 有线共享（控制robot常用）** |
| 已连接的上行接口 | 刚才连接的无线网卡 |
| 面向从机的下行接口 | 接网线到机器人的有线网卡 |
| 连接名称 | `机器人控制网络` |
| 网段 | `192.168.1.0/24`，也可填 `192.168.1` |
| 主机地址末段 | `20` |
| 从机地址末段 | `30` |
| DHCP 地址池／地址使用方式 | 按下述方法避开固定 `.30` |
| 成功后开机自动启用此下行 | 按使用需要选择，通常填 `y` |

软件显示当前出口后，核对它是否为预期无线接口。共享出口跟随主机系统路由；如果提示输入 `FOLLOW`，先核对其他连接或 VPN 是否改变了出口，再决定是否接受当前路由。

支持自定义 DHCP 池时，对“设置自定义 DHCP 地址池”选 `y`，起点填 `192.168.1.100`，终点填 `192.168.1.199`，为固定的 `.20` 和 `.30` 留出空间。

如果软件无法确认支持自定义池，则选 **2. 专用直连、仅一台静态从机；接受不能混接 DHCP 客户端**。此时按专用单机器人链路使用，不接入 DHCP 客户端；自动地址池不会为 `.30` 创建保留租约。

核对计划中下行地址为 `192.168.1.20/24`、连接名称为 `机器人控制网络`，按提示执行地址占用探测并确认试运行。

### 3. 配置机器人并确认

保持主机向导等待确认，在机器人上执行[客户端静态 IP 教程](02_客户端静态IP.md)。两端完成试运行后，在主机另一终端执行：

```bash
ping -c 3 192.168.1.30
```

在机器人上检查能否访问主机的 `.20`，并按第二篇教程测试 DNS 和直接 HTTPS。需要 SSH 控制时，再使用已有账号验证机器人 SSH。

验证通过后，分别回到机器人和主机的向导输入完整大写 `KEEP`。两端各有自己的试运行事务，确认其中一端不会确认另一端。主机本身能上网也不能代替机器人联网验证。

## 完成结果

主机无线连接保持上行；主机有线连接 `机器人控制网络` 使用 `192.168.1.20/24`，并提供 IPv4 共享。机器人使用 `.30` 的操作在第二篇教程完成。试运行超时或未确认时，按软件提示检查恢复结果后重试。

需要停止共享但继续使用 `.20` 管理机器人时，可在主菜单选择 **8. 停止有线共享但保留管理地址**，按提示试运行并确认。更多说明见[主机共享与本地管理](../02_主机共享与本地管理.md)。
